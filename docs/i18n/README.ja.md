# FaceExpressionVFX v3.11

[简体中文](README.zh-CN.md) · [English](../../README.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português (Brasil)](README.pt-BR.md) · [Русский](README.ru.md) · [繁體中文](README.zh-TW.md)

**顔の動きの推定値と、それを過信してはいけない理由を一緒に確認できます。**

FaceExpressionVFX は、FACS に着想を得た顔のアクションユニット（AU）の幾何特性を調べる開発者向けの、実験的なブラウザー作業環境です。カメラの処理はローカルで行われ、品質ゲート、キャリブレーション、不確実性によって処理の流れを検証できます。バージョン 3.11 は観察可能な動きの推定値と不確実性を報告します。個人の識別、意図、真偽、誠実さ、性格、心理学的・医学的診断は出力しません。

<a id="what-you-can-explore"></a>
## 探索できること

顔の動きのデモでは、数値の信頼性が低下する条件を説明せずに数値だけを表示しがちです。このプロジェクトは、動きの推定値とともに品質チェックと不確実性を可視化します。

- 眉、目、頬、鼻、唇、口の動きの概要を確認する。
- キャリブレーション、頭部姿勢、フレーム品質が出力に与える影響を見る。
- オプションのモデルを追加する前に、決定論的なルールとテストを調べる。
- 自分で選択した場合にのみ履歴を記録し、ローカルへのダウンロードとしてエクスポートする。

観察可能な顔の動きと、幾何ベースのパイプラインの限界を研究したい開発者や実験者を対象としています。人の感情や意図を推測するものではありません。

<a id="first-experiment"></a>
## 最初の実験

[実行と検証](#run-and-verify)に従ってアプリを起動します。十分な照明の下で無表情の顔から始め、キャリブレーション手順を実施してから、眉を上げる、口を開くなどの小さく目に見える動きを試してください。動きの値だけでなく、品質と不確実性の表示も確認します。

鮮明な正面像と、条件の難しい画像を比べると有用です。低品質のフレームは限られた証拠として扱うべきであり、顔についてより強い結論を出す根拠にすべきではありません。文書化されたパイプラインでは、推論の重みを下げる、または推論を一時停止できます。

実際のカメラによる録画は、ここにはまだ埋め込まれていません。同梱の合成評価が確認するのはテスト契約であり、人間の映像に対する精度ではありません。

<a id="three-useful-things-to-compare"></a>
### 比較すると役立つ三つの項目

| 実験 | 観察すること | 結論づけてはいけないこと |
| --- | --- | --- |
| 無表情の後、眉または口を小さく動かす | 動きの推定値とその区間 | 値が感情、誠実さ、意図を測定しているということ。 |
| 正面像の後、より難しい姿勢や照明条件にする | 品質スコア、信頼度、一時停止・重み低減の動作 | 画質の悪い画像が、その人についてより強い証拠を与えるということ。 |
| 明示的に短い録画を開始してからエクスポートする | ローカル履歴と JSON/CSV 出力 | エクスポートが検証済みの診断や実環境の精度報告であるということ。 |

インターフェースには中国語・英語の切り替え、履歴、JSON/CSV のエクスポート操作が含まれます。録画は意図的に行う操作であり、リアルタイムのパイプラインを確認するための必須条件ではありません。

<a id="v311-algorithm-pipeline"></a>
## v3.11 アルゴリズムのパイプライン

1. MediaPipe が 468 個以上の正規化された顔ランドマークを提供します。
2. フレーム品質ゲートが、ランドマークの完全性、顔の境界・スケール、頭部姿勢、照明、コントラスト、輝度のクリッピング、鮮明さ、目の領域の可視性・まぶしさの代理指標を採点します。
3. フレームは通過、信頼度の重み低減、または一時停止に分類されます。一時停止されたフレームは AU 推論や個人用キャリブレーションを更新できません。
4. 頑健な個人基準は中央値と中央絶対偏差（MAD）を用い、低品質のフレームや外れ値フレームを除外します。動きが少なく高品質なフレームでのみ、ゆっくりした範囲制限付きのドリフト更新を適用します。
5. AU 計算の前に、頭部姿勢の補正と顔の大きさで正規化した距離により、姿勢や個人に固有の安定した幾何形状の影響を減らします。
6. 各 AU は `value`、`lower`、`upper`、`confidence`、および解剖学的な `region` を返します。
7. 明示的持続時間のベイズ時系列フィルターが、フレーム数に基づくヒステリシスに代わり、事後信頼度と正規化された不確実性を報告します。
8. AU 推定値から、区間の伝播を伴う十二種類の観察可能な動きの概要を導出します。

学習済みモデルは同梱していません。オプションの AU プロバイダーは、メタデータに名前、バージョン、ライセンス、学習データの来歴、AU ラベルマップ、評価指標が含まれている場合にのみ有効になります。その寄与には品質に応じた重みと上限が適用され、決定論的な幾何ルールがフォールバックとして維持されます。

<a id="run-and-verify"></a>
## 実行と検証

Node.js/npm、カメラを利用できる最新のブラウザー、動作するカメラを準備します。リポジトリのルートから実行してください。カメラアクセスには `localhost` または HTTPS を使い、MediaPipe の CDN スクリプトとウェブフォントへのネットワークアクセスを許可してください。フレームをローカルで処理しても、初回起動が完全にオフラインになるわけではありません。

```powershell
npm install
npm run check
npm start
```

`npm start` はポート 8080 で静的サーバーを起動し、ブラウザーで開くよう要求します。必要に応じて `http://localhost:8080` を自分で開いてください。このコマンドは `npx http-server` を使用し、初回使用時にサーバーをダウンロードすることがあります。

**最初に成功させる操作：** ライブのキャリブレーション・品質パネルを確認し、一つの目に見える動きをして、その推定値を不確実性表示と比較してください。コマンドラインのチェックに合格しても、このカメラ確認の代わりにはなりません。

`npm run check` は、単体・契約テスト、決定論的な AU 指標フィクスチャ、ESLint、静的なリリースチェックを実行します。評価 CLI は、AU ごとの適合率、再現率、F1、偽陽性率、およびホールドアウトした被験者の集計を報告します。

```powershell
node scripts/evaluate-au.mjs evaluation/fixtures/synthetic-au-eval.json
```

同梱のベクトルは合成データによる契約テストであり、実環境での精度の証拠ではありません。固定動画マニフェストの要件は [evaluation/README.md](../../evaluation/README.md) を参照してください。v3.11 では、再配布可能で合法的にラベル付けされた人間の動画データセットが用意されていなかったため、このリリースは実動画での精度や個人をまたぐ汎化性能を主張しません。

<a id="main-modules"></a>
## 主なモジュール

- `face-quality.js` — フレームゲートと AU 信頼区間
- `face-au-detector.js` — 頑健なキャリブレーション、姿勢補正、決定論的な AU 幾何計算
- `face-temporal.js` — 明示的持続時間のベイズ状態フィルター
- `face-observables.js` — 直接観察可能な動きの概要
- `face-model-adapter.js` — 来歴の確認を条件とするオプションの分類器とルールへのフォールバック
- `scripts/evaluate-au.mjs` — 固定マニフェストによる AU 指標と被験者ホールドアウト報告

<a id="common-questions"></a>
## よくある質問

**これは感情検出器ですか？** いいえ。出力は幾何形状と動きの代理指標であり、心理状態のラベルではありません。

**なぜ推論が一時停止したり、信頼度が下がったりするのですか？** 品質ゲートは、姿勢、可視性、照明、その他のフレーム条件を考慮します。品質表示を確認して映り方を改善してください。一時停止された結果を、その人に関する否定的な所見として解釈しないでください。

**学習済み AU モデルは含まれていますか？** いいえ。同梱のパイプラインは決定論的な幾何処理を使用します。オプションのプロバイダーが寄与するには、メタデータ、来歴、ライセンス、評価情報が必要です。

**合成評価で、自分のカメラにおける精度が証明されますか？** いいえ。検証するのは指標・テストの契約です。実動画での検証には、適切かつ合法的にラベル付けされた評価セットと、[evaluation/README.md](../../evaluation/README.md) の固定マニフェスト手順が必要です。

**記録した履歴はどこにありますか？** 録画を開始した後、ブラウザーのローカル IndexedDB に保存されます。エクスポートはローカルへのダウンロードです。自動アップロードされなくても、録画とエクスポートは個人データとして扱ってください。

<a id="privacy-and-limits"></a>
## プライバシーと制限

カメラのフレームはブラウザー内で処理されます。このプロジェクトは何もアップロードしません。履歴はユーザーが録画を開始した後にのみ記録され、ローカルの IndexedDB に保持されます。エクスポートは明示的なローカルダウンロードです。FaceExpressionVFX を個人識別、監視、医療、雇用、保険、警察活動、教育上の懲戒、その他の重大な影響を及ぼす意思決定に使用しないでください。[PRIVACY.md](../../PRIVACY.md) を参照してください。

<a id="help-improve-the-experiment"></a>
## 実験の改善に協力する

結果を検証できる分野での貢献を歓迎します。

- フレーム品質とキャリブレーションの境界事例。
- アクセシブルなラベル、より明確な不確実性の説明、翻訳の改善。
- AU の幾何計算と時間的挙動の回帰テスト。
- 適切なライセンスと同意を得たデータを使う、再現可能な評価ツール。

| 貢献分野 | 最初に確認するファイル | 有用な証拠 |
| --- | --- | --- |
| フレーム品質の境界事例 | `face-quality.js`、`face-policies.js` | 焦点を絞った回帰事例と、期待する通過・重み低減・一時停止の挙動。 |
| キャリブレーションまたは AU 幾何計算 | `face-au-detector.js`、`face-temporal.js` | 決定論的な入力列と、明示された期待出力の境界。 |
| 言語と UI の明確さ | `face-i18n.js`、`index.html` | 両方の言語状態と、不確実性の意味を維持する説明。 |
| 評価ツール | `scripts/evaluate-au.mjs`、`evaluation/README.md` | マニフェスト・スキーマのチェック。合成データの証拠と実動画の証拠は別々に明示してください。 |

関連するモジュールと `npm run check` から始めてください。[プルリクエスト](https://github.com/son-gladyso/FaceExpressionVFX/pulls) では、問題、証拠、実際に実行したテスト、未検証の事項を説明してください。大きな変更は、実装前に [issue](https://github.com/son-gladyso/FaceExpressionVFX/issues) で議論してください。

共有する権利や許可がない私的な顔の録画、生体認証用の埋め込み表現、モデルの重み、データセットを提供しないでください。観察可能な動きと、個人の識別、感情、意図、健康に関する主張との区別を維持してください。
