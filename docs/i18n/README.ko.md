# FaceExpressionVFX v3.11

[简体中文](README.zh-CN.md) · [English](../../README.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português (Brasil)](README.pt-BR.md) · [Русский](README.ru.md) · [繁體中文](README.zh-TW.md)

**얼굴 움직임 추정값과 함께, 그 값을 덜 신뢰해야 하는 이유도 확인하세요.**

FaceExpressionVFX는 FACS에서 착안한 얼굴 동작 단위(AU)의 기하학을 탐구하는 개발자를 위한 실험용 브라우저 작업 환경입니다. 카메라 처리는 로컬에서 이루어지며, 품질 게이트, 보정, 불확실성을 통해 파이프라인을 점검할 수 있습니다. 버전 3.11은 관찰 가능한 움직임의 추정값과 불확실성을 보고합니다. 신원, 의도, 진실성, 진정성, 성격 또는 심리·의학적 진단은 출력하지 않습니다.

<a id="what-you-can-explore"></a>
## 탐구할 수 있는 것

얼굴 움직임 데모는 수치가 언제 신뢰하기 어려워지는지 설명하지 않고 숫자만 보여 주는 경우가 많습니다. 이 프로젝트는 움직임 추정값과 함께 품질 검사와 불확실성을 표시합니다.

- 눈썹, 눈, 볼, 코, 입술, 입 움직임 요약을 살펴봅니다.
- 보정, 머리 자세, 프레임 품질이 출력에 미치는 영향을 확인합니다.
- 선택적 모델을 추가하기 전에 결정론적 규칙과 테스트를 살펴봅니다.
- 직접 선택한 경우에만 기록을 저장하고, 로컬 다운로드로 내보냅니다.

관찰 가능한 얼굴 움직임과 기하학 기반 파이프라인의 한계를 연구하려는 개발자와 실험자를 위한 프로젝트입니다. 사람이 무엇을 느끼거나 의도하는지는 추론하지 않습니다.

<a id="first-experiment"></a>
## 첫 실험

[실행 및 검증](#run-and-verify)에 따라 앱을 시작하세요. 조명이 충분한 곳에서 중립적인 표정으로 시작하고 보정 절차를 따른 다음, 눈썹을 올리거나 입을 여는 것처럼 작고 눈에 보이는 움직임을 시도하세요. 움직임 값뿐 아니라 품질 및 불확실성 표시도 관찰하세요.

선명한 정면 모습과 더 까다로운 조건의 모습을 비교하면 유용합니다. 저품질 프레임은 제한적인 증거로 취급해야 하며, 얼굴에 대해 더 강한 결론을 내리는 근거로 삼아서는 안 됩니다. 문서에 설명된 파이프라인은 추론의 가중치를 낮추거나 추론을 일시 중지할 수 있습니다.

실제 카메라 녹화 영상은 아직 여기에 포함되어 있지 않습니다. 기본 제공 합성 평가는 테스트 계약을 확인하며, 사람 영상에 대한 정확도를 확인하지는 않습니다.

<a id="three-useful-things-to-compare"></a>
### 비교하면 유용한 세 가지

| 실험 | 관찰할 사항 | 내려서는 안 되는 결론 |
| --- | --- | --- |
| 중립적인 표정을 지은 뒤 눈썹이나 입을 조금 움직이기 | 움직임 추정값과 그 구간 | 어떤 값이 감정, 진정성 또는 의도를 측정한다는 결론. |
| 정면을 보다가 더 까다로운 자세나 조명 조건으로 바꾸기 | 품질 점수, 신뢰도, 일시 중지·가중치 감소 동작 | 품질이 낮은 이미지가 그 사람에 관해 더 강한 증거를 제공한다는 결론. |
| 명시적으로 짧은 녹화를 시작한 뒤 내보내기 | 로컬 기록과 JSON/CSV 출력 | 내보내기 결과가 검증된 진단이나 실제 환경 정확도 보고서라는 결론. |

인터페이스에는 중국어/영어 전환, 기록, JSON/CSV 내보내기 컨트롤이 있습니다. 녹화는 사용자가 의도적으로 선택하는 작업이며, 실시간 파이프라인을 살펴보기 위한 필수 조건이 아닙니다.

<a id="v311-algorithm-pipeline"></a>
## v3.11 알고리즘 파이프라인

1. MediaPipe가 정규화된 얼굴 랜드마크 468개 이상을 제공합니다.
2. 프레임 품질 게이트가 랜드마크 완전성, 얼굴 경계·크기, 머리 자세, 조명, 대비, 명암 잘림, 선명도, 눈 영역 가시성·눈부심 대리 지표를 평가합니다.
3. 프레임은 통과하거나, 신뢰도 가중치가 낮아지거나, 처리가 일시 중지됩니다. 일시 중지된 프레임은 AU 추론이나 개인 보정을 갱신할 수 없습니다.
4. 강건한 개인 기준선은 중앙값과 중앙값 절대 편차(MAD)를 사용하고, 품질이 낮거나 이상치인 프레임을 거부하며, 움직임이 적고 품질이 높은 프레임에서만 느리고 제한된 드리프트 갱신을 적용합니다.
5. AU 계산 전에 머리 자세 보정과 얼굴 크기로 정규화한 거리를 사용하여 자세 및 안정적인 개인별 얼굴 기하학의 영향을 줄입니다.
6. 각 AU는 `value`, `lower`, `upper`, `confidence`와 해부학적 `region`을 반환합니다.
7. 명시적 지속 시간 베이지안 시간 필터가 프레임 수 기반 히스테리시스를 대체하고, 사후 신뢰도와 정규화된 불확실성을 보고합니다.
8. AU 추정값에서 관찰 가능한 움직임 요약 12개를 도출하며, 구간도 함께 전파합니다.

학습된 모델은 기본 제공되지 않습니다. 선택적 AU 제공자는 메타데이터에 이름, 버전, 라이선스, 학습 데이터 출처, AU 라벨 매핑, 평가 지표가 포함되어 있을 때만 활성화됩니다. 기여도에는 품질에 따른 가중치와 상한이 적용되며, 결정론적 기하학 규칙이 대체 수단으로 유지됩니다.

<a id="run-and-verify"></a>
## 실행 및 검증

Node.js/npm, 카메라를 지원하는 최신 브라우저, 정상 작동하는 카메라를 준비하세요. 저장소 루트에서 실행합니다. 카메라에 접근하려면 `localhost` 또는 HTTPS를 사용하고, MediaPipe CDN 스크립트와 웹 글꼴에 대한 네트워크 접근을 허용하세요. 프레임을 로컬에서 처리한다고 해서 첫 실행이 완전히 오프라인인 것은 아닙니다.

```powershell
npm install
npm run check
npm start
```

`npm start`는 포트 8080에서 정적 서버를 실행하고 브라우저에서 열도록 요청합니다. 필요하면 직접 `http://localhost:8080`을 여세요. 이 명령은 `npx http-server`를 사용하며, 처음 사용할 때 서버를 다운로드할 수 있습니다.

**처음 성공적으로 해 볼 작업:** 실시간 보정/품질 패널을 확인하고, 눈에 보이는 동작 하나를 수행한 뒤, 추정값을 불확실성 표시와 비교하세요. 명령줄 검사를 통과해도 이 카메라 확인을 대신할 수는 없습니다.

`npm run check`는 단위/계약 테스트, 결정론적 AU 지표 테스트 픽스처, ESLint, 정적 릴리스 검사를 실행합니다. 평가 CLI는 AU별 정밀도, 재현율, F1, 거짓 양성률과 함께 홀드아웃 피험자 요약을 보고합니다.

```powershell
node scripts/evaluate-au.mjs evaluation/fixtures/synthetic-au-eval.json
```

기본 제공 벡터는 합성 계약 테스트이며, 실제 환경 정확도의 증거가 아닙니다. 고정 영상 매니페스트 요구 사항은 [evaluation/README.md](../../evaluation/README.md)를 참조하세요. v3.11에는 재배포가 가능하고 적법하게 라벨이 부여된 사람 영상 데이터셋이 없었으므로, 이 릴리스는 실제 영상 정확도나 서로 다른 사람에 대한 일반화 성능을 주장하지 않습니다.

<a id="main-modules"></a>
## 주요 모듈

- `face-quality.js` — 프레임 게이트와 AU 신뢰 구간
- `face-au-detector.js` — 강건한 보정, 자세 보상, 결정론적 AU 기하학
- `face-temporal.js` — 명시적 지속 시간 베이지안 상태 필터
- `face-observables.js` — 직접 관찰 가능한 움직임 요약
- `face-model-adapter.js` — 출처 검증 조건이 적용되는 선택적 분류기와 규칙 기반 대체 수단
- `scripts/evaluate-au.mjs` — 고정 매니페스트 AU 지표와 피험자 홀드아웃 보고서

<a id="common-questions"></a>
## 자주 묻는 질문

**감정 감지기인가요?** 아닙니다. 출력은 기하학과 움직임의 대리 지표이며, 정신 상태 라벨이 아닙니다.

**추론이 일시 중지되거나 신뢰도가 떨어지는 이유는 무엇인가요?** 품질 게이트는 자세, 가시성, 조명 및 기타 프레임 조건을 고려합니다. 품질 표시를 확인하고 촬영 조건을 개선하세요. 일시 중지된 결과를 그 사람에 대한 부정적인 발견으로 해석하지 마세요.

**학습된 AU 모델이 포함되어 있나요?** 아닙니다. 기본 제공 파이프라인은 결정론적 기하학을 사용합니다. 선택적 제공자가 기여하려면 메타데이터, 출처, 라이선스, 평가 정보가 필요합니다.

**합성 평가가 내 카메라의 정확도를 입증하나요?** 아닙니다. 지표/테스트 계약을 검증할 뿐입니다. 실제 영상 검증에는 적합하고 적법하게 라벨이 부여된 평가 세트와 [evaluation/README.md](../../evaluation/README.md)의 고정 매니페스트 절차가 필요합니다.

**저장한 기록은 어디에 있나요?** 녹화를 시작한 뒤 브라우저의 로컬 IndexedDB에 저장됩니다. 내보내기는 로컬 다운로드입니다. 녹화와 내보내기 파일은 자동으로 업로드되지 않더라도 개인 데이터로 취급하세요.

<a id="privacy-and-limits"></a>
## 개인정보 보호 및 한계

카메라 프레임은 브라우저에서 처리됩니다. 이 프로젝트는 아무것도 업로드하지 않습니다. 기록은 사용자가 녹화를 시작한 후에만 저장되며 로컬 IndexedDB에 남습니다. 내보내기는 명시적으로 실행하는 로컬 다운로드입니다. FaceExpressionVFX를 신원 식별, 감시, 의료, 고용, 보험, 치안, 교육상 징계 또는 그 밖의 중대한 영향을 미치는 의사결정에 사용하지 마세요. [PRIVACY.md](../../PRIVACY.md)를 참조하세요.

MIT 라이선스입니다. 타사 라이브러리와 향후 추가될 데이터셋/모델에는 각각의 라이선스가 유지됩니다.

<a id="help-improve-the-experiment"></a>
## 실험 개선에 기여하기

결과를 검증할 수 있는 영역의 기여를 환영합니다.

- 프레임 품질 및 보정의 경계 사례.
- 접근성을 고려한 라벨, 더 명확한 불확실성 설명, 번역 개선.
- AU 기하학 및 시간적 동작의 회귀 테스트.
- 적절한 라이선스와 동의를 확보한 데이터를 사용하는 재현 가능한 평가 도구.

| 기여 영역 | 시작할 파일 | 유용한 증거 |
| --- | --- | --- |
| 프레임 품질 경계 사례 | `face-quality.js`, `face-policies.js` | 초점이 명확한 회귀 사례와 예상되는 통과/가중치 감소/일시 중지 동작. |
| 보정 또는 AU 기하학 | `face-au-detector.js`, `face-temporal.js` | 결정론적 입력 시퀀스와 명시적인 예상 출력 경계. |
| 언어 및 UI 명확성 | `face-i18n.js`, `index.html` | 두 언어 상태와 불확실성을 보존하는 설명. |
| 평가 도구 | `scripts/evaluate-au.mjs`, `evaluation/README.md` | 매니페스트/스키마 검사. 합성 증거와 실제 영상 증거를 구분하여 표시하세요. |

관련 모듈과 `npm run check`부터 시작하세요. [풀 리퀘스트](https://github.com/son-gladyso/FaceExpressionVFX/pulls)에서 문제, 증거, 실제로 실행한 테스트, 아직 검증되지 않은 사항을 설명하세요. 큰 변경은 구현 전에 [이슈](https://github.com/son-gladyso/FaceExpressionVFX/issues)에서 논의하세요.

공유할 권리와 허가 없이 개인 얼굴 녹화, 생체 인식 임베딩, 모델 가중치 또는 데이터셋을 기여하지 마세요. 관찰 가능한 움직임과 신원, 감정, 의도 또는 건강에 관한 주장 사이의 구분을 유지하세요.
