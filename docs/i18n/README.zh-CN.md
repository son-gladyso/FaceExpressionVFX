# FaceExpressionVFX v3.11

[简体中文](README.zh-CN.md) · [English](../../README.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português (Brasil)](README.pt-BR.md)

**查看面部运动估计，同时了解为什么不应过度相信这些估计。**

FaceExpressionVFX 是一个实验性的浏览器工作台，供开发者探索受 FACS 启发的面部动作单元（AU）几何特征。摄像头处理在本地进行；质量门控、校准和不确定性使整个处理流程可供检查。3.11 版报告可观察的运动估计及其不确定性，不输出身份、意图、真实性、真诚程度、人格特征，也不提供心理或医学诊断。

[首次实验](#first-experiment) · [本地运行](#run-and-verify) · [处理流程](#v311-algorithm-pipeline) · [常见问题](#common-questions) · [参与贡献](#help-improve-the-experiment)

<a id="what-you-can-explore"></a>
## 可以探索什么

面部运动演示经常只显示一个数值，却不说明它何时会变得不可靠。本项目将质量检查和不确定性与运动估计一并展示。

- 查看眉毛、眼睛、脸颊、鼻子、嘴唇和嘴部的运动摘要。
- 了解校准、头部姿态和帧质量如何影响输出。
- 在添加可选模型之前，探索确定性规则和测试。
- 仅在你主动选择时记录历史，然后将其导出为本地下载文件。

本项目面向希望研究可观察的面部运动以及基于几何特征的处理流程局限性的开发者和实验者。它不推断一个人的感受或意图。

<a id="first-experiment"></a>
## 首次实验

按照[运行与验证](#run-and-verify)启动应用。首先保持光线充足、面部中性，完成校准流程，然后尝试一个小幅、可见的动作，例如抬眉或张嘴。除了运动数值，也要观察质量和不确定性指示器。

一个有用的比较是清晰的正面视角与更困难的视角。低质量帧应被视为有限的证据，而不是得出更强面部结论的依据。文档描述的处理流程能够降低推断权重或暂停推断。

这里尚未嵌入真实摄像头录像。随附的合成评估检查测试契约，而不是在人类视频上的准确性。

<a id="three-useful-things-to-compare"></a>
### 三项值得比较的内容

| 实验 | 观察内容 | 不应得出的结论 |
| --- | --- | --- |
| 保持面部中性，然后做一个小幅抬眉或嘴部动作 | 运动估计及其区间 | 某个数值衡量了情绪、真诚程度或意图。 |
| 先使用正面视角，然后改变为更困难的姿态或光照条件 | 质量分数、置信度以及暂停或降权行为 | 质量较差的图像提供了更强的个人证据。 |
| 明确开始一段短录制，然后导出 | 本地历史记录和 JSON/CSV 输出 | 导出结果是经过验证的诊断或真实环境准确性报告。 |

界面包含中英文切换、历史记录以及 JSON/CSV 导出控件。录制是主动操作，并不是检查实时处理流程的前提。

<a id="v311-algorithm-pipeline"></a>
## v3.11 算法处理流程

1. MediaPipe 提供 468 个以上的归一化面部关键点。
2. 帧质量门控对关键点完整性、面部边界与尺度、头部姿态、照明、对比度、明暗截断、清晰度以及眼部区域可见性／眩光代理指标进行评分。
3. 帧会被放行、降低置信度权重或暂停处理。暂停的帧不能更新 AU 推断或个人校准。
4. 稳健的个人基线使用中位数和中位数绝对偏差（MAD），拒绝低质量帧和离群帧，并且仅对静止、质量较高的帧施加缓慢且限幅的漂移更新。
5. 在计算 AU 之前，通过头部姿态补偿和按面部尺度归一化的距离，减少姿态以及稳定的个体几何特征带来的影响。
6. 每个 AU 返回 `value`、`lower`、`upper`、`confidence` 和解剖学 `region`。
7. 显式持续时间贝叶斯时序滤波器替代基于帧计数的滞回机制，并报告后验置信度和归一化不确定性。
8. 根据 AU 估计派生出十二种可观察的运动摘要，并传播相应的区间。

本项目不附带任何训练得到的模型。可选 AU 提供方只有在其元数据包含名称、版本、许可证、训练数据来源、AU 标签映射和评估指标时才能启用。其贡献按质量加权并设有上限；确定性几何规则始终作为回退方案。

<a id="run-and-verify"></a>
## 运行与验证

准备 Node.js/npm、支持摄像头的现代浏览器，以及可正常工作的摄像头。从仓库根目录运行。使用 `localhost` 或 HTTPS 访问摄像头，并允许网络访问 MediaPipe CDN 脚本和网页字体。本地帧处理并不意味着首次启动完全离线。

```powershell
npm install
npm run check
npm start
```

`npm start` 会在 8080 端口启动静态服务器，并请求浏览器打开它。如有需要，请自行打开 `http://localhost:8080`。该命令使用 `npx http-server`，首次使用时可能会下载服务器。

**首次成功操作：** 查看实时校准／质量面板，做出一个可见动作，并将其估计值与不确定性显示进行比较。通过命令行检查不能代替这项摄像头检查。

`npm run check` 会运行单元／契约测试、确定性 AU 指标测试夹具、ESLint 和静态发布检查。评估 CLI 报告各 AU 的精确率、召回率、F1 和假阳性率，以及留出受试者的汇总：

```powershell
node scripts/evaluate-au.mjs evaluation/fixtures/synthetic-au-eval.json
```

随附的向量是合成契约测试，不是真实环境准确性的证据。固定视频清单的要求请参阅 [evaluation/README.md](../../evaluation/README.md)。v3.11 没有可再分发且经过合法标注的人类视频数据集，因此本版本不声称具有真实视频准确性或跨个体泛化能力。

<a id="main-modules"></a>
## 主要模块

- `face-quality.js` — 帧门控和 AU 置信区间
- `face-au-detector.js` — 稳健校准、姿态补偿、确定性 AU 几何计算
- `face-temporal.js` — 显式持续时间贝叶斯状态滤波器
- `face-observables.js` — 可直接观察的运动摘要
- `face-model-adapter.js` — 受来源要求约束的可选分类器和规则回退
- `scripts/evaluate-au.mjs` — 基于固定清单的 AU 指标和受试者留出报告

<a id="common-questions"></a>
## 常见问题

**这是情绪检测器吗？** 不是。输出是几何和运动的代理指标，而不是心理状态标签。

**为什么推断会暂停或置信度会下降？** 质量门控会考虑姿态、可见性、照明和其他帧条件。请查看质量指示器并改善画面，而不是把暂停结果解读为关于该人的负面发现。

**是否包含训练得到的 AU 模型？** 不包含。随附的处理流程使用确定性几何方法。可选提供方需要提供元数据、来源、许可和评估信息，才能参与计算。

**合成评估能证明在我的摄像头上的准确性吗？** 不能。它验证的是指标／测试契约。真实视频验证需要合适且经过合法标注的评估集，并遵循 [evaluation/README.md](../../evaluation/README.md) 中的固定清单流程。

**录制的历史记录在哪里？** 开始录制后，记录保存在浏览器本地的 IndexedDB 中。导出是本地下载；即使录制内容和导出文件不会自动上传，也应将其视为个人数据。

<a id="privacy-and-limits"></a>
## 隐私与限制

摄像头帧在浏览器中处理。本项目不会上传任何内容。只有用户开始录制后才会记录历史，且记录保存在本地 IndexedDB 中；导出是明确触发的本地下载。请勿将 FaceExpressionVFX 用于身份识别、监控、医疗保健、就业、保险、警务、教育惩戒或其他高影响决策。请参阅 [PRIVACY.md](../../PRIVACY.md)。

<a id="help-improve-the-experiment"></a>
## 帮助改进实验

欢迎在结果可以验证的领域贡献：

- 帧质量和校准的边界情况。
- 无障碍标签、更清晰的不确定性说明，以及翻译改进。
- AU 几何计算和时序行为的回归测试。
- 使用经过适当许可并取得同意的数据，构建可复现的评估工具。

| 贡献领域 | 建议从这些文件入手 | 有用的证据 |
| --- | --- | --- |
| 帧质量边界情况 | `face-quality.js`、`face-policies.js` | 聚焦的回归案例，以及预期的放行／降权／暂停行为。 |
| 校准或 AU 几何计算 | `face-au-detector.js`、`face-temporal.js` | 确定性输入序列，以及明确的预期输出边界。 |
| 语言和界面清晰度 | `face-i18n.js`、`index.html` | 两种语言状态，以及保留不确定性含义的说明。 |
| 评估工具 | `scripts/evaluate-au.mjs`、`evaluation/README.md` | 清单／模式检查；分别标注合成证据与真实视频证据。 |

从相关模块和 `npm run check` 开始。在 [pull request](https://github.com/son-gladyso/FaceExpressionVFX/pulls) 中说明问题、证据、实际运行的测试，以及仍未验证的部分。较大的变更请先在 [issue](https://github.com/son-gladyso/FaceExpressionVFX/issues) 中讨论，再着手实现。

没有相应的分享权利和许可时，请勿贡献私人面部录像、生物识别嵌入、模型权重或数据集。请保留可观察运动与关于身份、情绪、意图或健康的主张之间的区别。
